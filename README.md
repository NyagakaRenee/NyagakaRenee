## 🔭 Featured project: Nyagaka Enterprises Home Lab

A simulated small-business network, built and hardened end-to-end as a
real case study — not a follow-the-instructions lab.

**Stage 1 (13 weeks, complete):**
- ☁️ **Cloud migration** — moved a 3-server network to Oracle Cloud with
  layered firewalls, IP-restricted SSH, and a tested recovery path
- 🐍 **Security automation** — a Python log-shipping pipeline detecting SSH
  brute-force, account changes, and sudo escalation attempts
- 🛡️ **SIEM** — Wazuh with custom correlation rules, file integrity
  monitoring, mapped to the Kenya Data Protection Act
- 🧱 **WAF** — Nginx + ModSecurity + OWASP CRS, compiled from source on
  ARM64, verified in detection-only mode before going live
- 🔑 **Identity** — a Windows Server 2025 Active Directory forest, OU
  structure, and account lockout policy — proven with a real forced
  lockout, not just a config read
- ✅ **End-to-end validation** — live SSH brute-force and SQL injection
  attacks traced through to real SIEM alerts, with measured detection
  latency

24 real bugs hit and fixed along the way, every one logged with its actual
root cause, not just the fix.
